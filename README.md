# Лабораторная работа № 3

* **Студент:** Пылинский Даниил Максимович
* **Группа:** ПИ 1-1
* **Тема:** Условные операторы `if` и `if else`
* **Назначение программы:** Анализ целого числа (определение знака и чётности) и расчёт стоимости билета в зависимости от возраста пассажира.

## Порядок проверки условий (задача «Стоимость билета»)

1. Сначала с помощью логического «ИЛИ» (`||`) проверяется корректность возраста (`age < 0 || age > 120`), чтобы сразу отсеять ошибочные данные до проверки ценовых категорий.
2. Далее допустимые значения проверяются последовательно по возрастанию границ (`<= 6`, `<= 17`, `<= 59`, иначе `60..120`). Благодаря цепочке `if — else if — else` срабатывает ровно одна подходящая ветвь.
